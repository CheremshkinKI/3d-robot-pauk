# FIELD / LAB

Open `index.html` in a modern browser with WebGL and an internet connection. No installation or backend is required. Three.js 0.170.0 and OrbitControls load from jsDelivr; this is a single application file, not an offline bundle. Styling and telemetry charts are implemented directly with CSS and Canvas.

Press Start to run, Pause to freeze simulation time, or Step to complete one measurement. Use mouse drag, right-drag and wheel to orbit, pan and zoom. Export measurements creates a CSV including coordinates, voltages, phase, all 20 raw packets, filtering statistics and stability decisions. Manual sliders restart the experiment at the changed position or voltage configuration.

The four exploration strategies and four fine optimizers are implemented separately. Bayesian optimization uses an RBF Gaussian process with Cholesky decomposition and UCB candidate selection, with robot moves capped at 5 cm. Coarse exploration uses a 40-point budget (125 for the snake grid) or an adaptive stable-signal trigger. Fine search uses 42 points; refinement uses a 25-point cross at 5 mm spacing. Voltage search evaluates eight levels for each of four scatterers sequentially. Final rollback restores both the best stable coordinate and its associated voltage state.

The model is illustrative, not a calibrated electromagnetic or mechanical solver. The NLoS scenario attenuates the direct ray globally. Cable lengths are exact Euclidean inverse kinematics; tension feasibility, acceleration limits and obstacle collisions are not solved. Spatial searching does not certify a global optimum. Gain from voltage tuning is computed rather than guaranteed. The 3 dB gate is applied to unfiltered packets, so Gaussian ESP32 noise alone often causes rejection. If no batch is stable, the run reports that outcome rather than inventing a stable optimum. The gain baseline is the first filtered batch, even if that batch fails the stability gate.

Validation: JavaScript syntax check passed; a Node harness exercised 96 complete combinations of four exploration strategies, four optimizers, two sensors and three modes with simulated rendering. It verified termination, bounds, batch size, quantization, rejection and final rollback. 91 combinations found a stable result; five correctly reported none. Browser smoke testing confirmed rendering and single-step acquisition. A sustained 60 FPS performance benchmark was not performed; performance depends on GPU, viewport and browser.
